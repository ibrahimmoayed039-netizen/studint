# حضور الطلبة (NFC)

برنامج سطح مكتب (Electron) لتسجيل حضور الطلبة عبر قارئ بطاقات NFC.

## طريقة عمل القارئ
معظم قارئات NFC/RFID الـ USB تعمل كلوحة مفاتيح: تكتب رقم البطاقة ثم Enter.
البرنامج يلتقط هذا الرقم تلقائياً في تبويب "تسجيل الحضور".

## التشغيل محلياً
npm install
npm start

## البناء على GitHub
ارفع كل الملفات (مع مجلد .github) إلى المستودع، ثم افتح Actions وحمّل ملف exe من Artifacts.

## الإصدار 1.1 — الأمان عند نهاية الحصة
- **خروج تلقائي** عند إنهاء الحصة (يدوياً أو تلقائياً من الجدول) مع رسالة في شاشة الدخول؛ يُعطَّل من الإعدادات (مفعّل افتراضياً).
- **حذف الطالب أو سجل الحضور** يتطلب كلمة مرور المدرّس (المستخدم الحالي أو أي مدير) **أو** تمرير بطاقة المدرّس الخاصة.
- **بطاقة المدرّس**: تبويب «المستخدمون» ← «قراءة البطاقة». لا تتكرر بين طالب ومدرّس.
- إصلاح: حفظ الواجهة لم يعد يكتب فوق المستخدمين/كلمات المرور في الملف، ولم تعد كلمات المرور المجزّأة تُرسَل للواجهة.
